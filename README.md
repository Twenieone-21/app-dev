# The Conjuring

## About the Movie

**The Conjuring** is a *supernatural horror film* released in 2013 and directed by James Wan.

> Based on the true case files of the Warrens.

---

## Main Cast

1. Vera Farmiga as Lorraine Warren
2. Patrick Wilson as Ed Warren
3. Lili Taylor as Carolyn Perron

## Why I Like It

- Great atmosphere and well-timed scares
- Strong performances from the cast
- Easy to rewatch with friends

### Fun Fact

The film follows paranormal investigators who help a family in a haunted farmhouse. The title uses the `conjure` meaning to call forth a spirit.
